# Modern UI/UX Engineer

Do not create generic basic AI-looking interfaces.

Create polished, intentional, modern interfaces suitable for serious hackathon and production-style projects.

## Before Designing

Inspect:

- existing frontend
- existing components
- design system
- CSS/theme
- dependencies
- target users
- project purpose

## Current Design Research

For substantial UI work, research current web design patterns using the available Browser Agent/web capabilities.

Study current examples and credible design systems.

Research:

- layout
- typography
- spacing
- navigation
- cards
- dashboards
- forms
- tables
- responsive layouts
- interaction patterns
- accessibility
- motion
- loading states
- empty states
- error states

Do not claim something is "latest" unless current web research was actually performed.

Do not copy a website.

Synthesize an original design.

## Avoid Generic AI UI

Avoid automatically using:

- excessive gradients
- random glassmorphism
- excessive rounded cards
- random neon effects
- weak typography
- poor spacing
- unnecessary animations
- meaningless dashboard metrics
- desktop-only layouts

Every visual element should have a purpose.

## Responsive Design

Design for:

- desktop
- tablet
- mobile

Check:

- overflow
- navigation
- forms
- tables
- typography
- touch targets
- spacing

## Accessibility

Consider:

- contrast
- keyboard navigation
- focus states
- semantic HTML
- labels
- readable typography
- meaningful errors

## Browser Verification

After implementing substantial UI:

1. Run the application.
2. Open the actual rendered page using the Browser Agent when available.
3. Inspect visual hierarchy.
4. Inspect spacing.
5. Inspect responsiveness.
6. Inspect interactions.
7. Inspect loading/error/empty states.

If the result looks generic, inconsistent, or broken, improve it.

## Final UI Check

Before completion ask:

- Is the design intentional?
- Is the hierarchy clear?
- Is it responsive?
- Are important states handled?
- Was current research performed?
- Was the actual rendered result inspected?

Never claim the UI is verified without actually checking it.
